## What is MindiMap?

MindiMap is a browser-based visual thinking suite. It combines **mind maps**, **flowcharts**, **task management**, and **Gantt charts** in one editor, with an AI assistant that generates full diagrams from a single sentence. No installs, no plugins, no third-party accounts. Works offline. Ships in **9 languages** with full right-to-left support.

> **AI drafts it, you polish it.** Describe your project and MindiMap's AI builds the full structure -- nodes, branches, dependencies, and timelines -- in seconds.

## Features

- **🧠 Mind Maps** -- Radial or tree layouts. Perfect for brainstorming, planning, note-taking.
- **📊 Flowcharts** -- 8 shape types, arrowheads, yes/no labels, loop-backs, merge nodes.
- **☑ Tasks** -- Same tree layout, but every node is a task with a checkbox and live progress bar.
- **📅 Gantt Charts** -- Full project timelines with dependencies and milestones. Built for companies and thesis presentations.
- **✨ AI Generation** -- Type a sentence, get a full map or flowchart. AI is metered; paid plans include 60-400 runs.
- **🎨 6 Themes** -- Light, dark, blue steel, soft, bright, natural. Each map remembers its own theme.
- **📱 QR Code Sharing** -- Share a map or chart instantly. Read-only links open without an account.
- **🤝 Editable Sharing** -- One editor at a time, versioned saves, automatic conflict resolution.
- **☁ Cloud Sync** -- Two-way sync across devices. Delete a map on one device, it disappears everywhere.
- **📤 Export Anywhere** -- PNG, JPEG, PDF, SVG, JSON, Markdown. No watermark on paid plans.
- **🌍 9 Languages** -- English, Persian, Turkish, Spanish, Chinese, Russian, German, Arabic, Italian.

## AI Assistant

MindiMap's AI is not a wrapper around ChatGPT. It runs on **our servers** using a model fine-tuned for visual structure. You pay per run, not per token.

- **Create a mind map** from a project description.
- **Create a flowchart** from an algorithm or process.
- **Create a Gantt chart** from a high-level project plan with real dates and dependencies.
- **Improve an existing map** by adding, removing, renaming, or restructuring nodes while preserving notes, icons, and colors.

**Example:**

> You: "Launch a new website over 3 months including design, development, testing, and marketing."
>
> MindiMap AI: generates a Gantt chart with 12 tasks, dependencies, and start/end dates.
