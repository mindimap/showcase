## Что такое MindiMap?

MindiMap — это визуальная среда для работы с информацией в браузере. Она объединяет интеллект-карты, блок-схемы, управление задачами и диаграммы Ганта в одном редакторе с ИИ-ассистентом, который создает полные диаграммы из одного предложения. Работает офлайн. Поддерживает 9 языков.

## Основные инструменты

### 🧠 Интеллект-карты
Радиальные или древовидные макеты. Идеально для мозгового штурма и планирования.

### 📊 Блок-схемы
8 типов фигур, стрелки, метки «Да/Нет» и циклы. Проектируйте алгоритмы визуально.

### ☑ Задачи
Каждый узел — это задача с чекбоксом и живым индикатором прогресса.

### 📅 Диаграммы Ганта
Полные графики проекта с зависимостями. Мгновенно преобразуйте карту в график с помощью ИИ. Идеально для отчетов и дипломных работ.

## Как ИИ помогает вам

- **Создание карты** из описания проекта.
- **Создание блок-схемы** из алгоритма.
- **Создание диаграммы Ганта** с реальными датами.
- **Улучшение существующих карт** с сохранением заметок и цветов.
