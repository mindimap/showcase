## Что такое MindiMap?
MindiMap — это визуальная среда для работы с информацией с поддержкой ИИ. Она объединяет интеллект-карты, блок-схемы, управление задачами и диаграммы Ганта в одном редакторе. ИИ-ассистент создает полные диаграммы из одного предложения.

## Основные инструменты
### 🧠 Интеллект-карты
Радиальные или древовидные макеты.

### 📊 Блок-схемы
8 типов фигур, стрелки, метки «Да/Нет».

### ☑ Задачи
Списки задач с визуальным отслеживанием прогресса.

### 📅 Диаграммы Ганта
Графики проекта с зависимостями. Мгновенно преобразуйте карту в график с помощью ИИ.
