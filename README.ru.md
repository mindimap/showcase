## Что такое MindiMap?
MindiMap — это визуальная среда для работы с информацией с поддержкой ИИ. Она объединяет интеллект-карты, блок-схемы, управление задачами и диаграммы Ганта в одном редакторе.

## Основные инструменты
### 🧠 Интеллект-карты
Радиальные или древовидные макеты.

### 📊 Блок-схемы
8 типов фигур.

### ☑ Задачи
Списки задач с отслеживанием прогресса.

### 📅 Диаграммы Ганта
Графики проекта с зависимостями.
