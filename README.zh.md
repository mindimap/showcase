## 什么是 MindiMap？

MindiMap 是一款基于浏览器的视觉思考工具。它将思维导图、流程图、任务管理和甘特图整合到一个编辑器中，并配有AI助手，可以从一句话生成完整的图表。无需安装，可离线使用，支持9种语言。

## 核心工具

### 🧠 思维导图
放射状或树状布局。非常适合头脑风暴和计划制定。

### 📊 流程图
8种形状类型，箭头，是/否标签和循环。可视化设计算法。

### ☑ 任务管理
每个节点都是一个任务，带有复选框和实时进度条。

### 📅 甘特图
带有依赖关系的完整项目时间表。使用AI瞬间将导图转换为甘特图。非常适合公司报告和论文展示。

## AI如何帮助您

- **创建思维导图**：通过项目描述。
- **创建流程图**：通过算法或过程。
- **创建甘特图**：带有真实的日期和依赖关系。
- **改进现有导图**：在不丢失笔记和颜色的情况下。
