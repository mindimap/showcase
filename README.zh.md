## 什么是 MindiMap？
MindiMap 是一款基于 AI 的视觉图表工具。它将思维导图、流程图、任务管理和甘特图整合到一个编辑器中。

## 核心工具
### 🧠 思维导图
放射状布局。

### 📊 流程图
可视化设计算法。

### ☑ 任务管理
带有进度条的任务列表。

### 📅 甘特图
项目时间表。
